# DeEd support

Public issue queue for catalogue corrections, product questions, accessibility problems and source-use concerns.

For catalogue corrections, include the public record ID, the issue and an official source. For a product question, describe the affected public page and the result you expected. Reports require maintainer review before catalogue facts change. Response times are not guaranteed.

Issues are public. Do not include passport numbers, application documents, private notes, personal contact details or other sensitive information. For application decisions or urgent deadline questions, contact the provider directly.

This repository contains support instructions and issue forms only.
